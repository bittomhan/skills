# 身份证正反面 → 一页 A4 复印页 PDF

把两张手机拍摄的证件照片（可能有任意角度偏转、倾斜、桌面背景）处理成一页 A4 PDF：转正 → 自动找四角 → 透视校正到证件实际尺寸 → 排版合成。无需 OpenCV，纯 numpy + PIL 即可。适用于任何人的证件（本人/家人/股东等）。

## 流程（每步都有坑，按顺序做）

### 1. 转正
照片里证件文字竖排 = 图被旋转了 90°。判断方向：人像/国徽在卡面右侧→照片是卡顺时针转 90° 拍的→用 `img.transpose(Image.ROTATE_90)`（逆时针）转正。

### 2. 找四角（核心，两种方法按可靠性排序）
- **首选：颜色掩码 + 边缘直线拟合**。证件卡面偏蓝白、桌面偏暖中性：`mask = (R−B) < −6`（对 9px 均值模糊后的 R−B）。每行取首个/末个 True 得左右边界，每列同理得上下边界，只取中段 10%~90% 避开圆角，robust polyfit（3 轮迭代剔离群点）拟合 4 条边直线，求交点得四角。
- **⚠️ 最大的坑**：`np.argmax(mask * idx)` 返回"最大值的首次出现"= 最后一个 True，边界方向全反。布尔数组直接 `mask.argmax(axis=1)` 才是首个 True。
- **⚠️ 阴影连通**：卡片上方的蓝色阴影在掩码里与卡面连成一片，会把顶边拉低 40~50px。对策：收紧阈值（如 R−B < −10.5，按图试）把阴影排除。
- **验证闭环（必做）**：把掩码染红半透明 + 绿色四边形叠加存图，用 Read 目检四边形是否贴合卡边。同时检查拟合宽高比（身份证 85.6/54 = 1.585，误差 <2% 即可信）。**不要靠目测网格图读坐标——实测误差可达 ±90px。**
- 兜底：叠加图上人工微调角点（±10px 级别）再重投影。

### 3. 透视校正
四角 → 单应矩阵（DLT：8×9 系数矩阵 SVD 取最小奇异向量），逆映射 + 双线性采样到 1011×638px（85.6×54mm @300dpi）。**四边形先向质心内缩 0.5%**（`quad = c + (quad−c)*0.995`），消除边缘带入的桌面色。越界像素填白。

### 4. 图像增强
每通道按 (0.5%, 99.5%) 分位拉伸——手机拍的暗图会变得干净明亮。

### 5. 合成 A4 PDF
- 画布 2480×3508（A4@300dpi）白底；卡片 1011×638 水平居中，上下两张（y≈1020 与 y≈1998）；每张上方 46px Noto Sans 标签「身份证 正面（人像面）/ 反面（国徽面）」，四周 2px 灰边框（160,160,160）。
- `canvas.save(out, "PDF", resolution=300.0)` → MediaBox 自动为 A4。
- 验证：`ls -la` 看大小 + `strings x.pdf | grep MediaBox` 应为 `[0 0 595.2 841.92]`。
- 中间产物（转正图、裁剪图、叠加图）存 /tmp/idcard/ 便于迭代；成品给绝对路径交付。

## 完整可用脚本

见本次会话工作日志同款实现（保存于技能目的无需附件，核心函数）：

```python
def homography(src, dst):  # DLT
    A = []
    for (x, y), (u, v) in zip(src, dst):
        A.append([x, y, 1, 0, 0, 0, -u*x, -u*y, -u])
        A.append([0, 0, 0, x, y, 1, -v*x, -v*y, -v])
    _, _, Vt = np.linalg.svd(np.array(A, dtype=np.float64))
    H = Vt[-1].reshape(3, 3)
    return H / H[2, 2]
# warp: Hinv @ [u,v,1] 归一化后双线性采样；oob 填 255
```
