# 三平台合规与内容规范

> 本文件为 biotom-content-pipeline skill 的详细合规参考，包含三平台公约、内容模板、引流路径规范。

## 一、六条纪律（三平台通用）

1. **身份**：统一"医药产业研究分享｜个人投资者视角"，不宣称任何金融专业身份（这是视频号认证的触发开关，也是抖音的禁区）
2. **内容三不**：不提买卖时机、不给目标价、不预测涨跌——个股投研=讲管线数据、竞争格局、催化剂日历、历史复盘，结论停在"逻辑与看法"层
3. **小红书加码**：不晒实盘收益、不教开户（尤其港美股）、不搬研报原文（数据自制图表）
4. **抖音加码**：科普化降敏（内容触发制，未认证不得发"证券专业深度分析"；讲行业事实+数字冲击，弱化投研结论）
5. **固定风险提示**：片尾+文末"个人研究分享，不构成投资建议"
6. **标签管理**：远离 #股票 #A股 #港股 #理财 #荐股

## 二、三平台公约要点

- **抖音**（2025-12《社区财经行业公约》）：内容触发制；禁虚拟货币；处罚限流→封号
- **视频号**（2026-04生效《金融行业公约》）：身份宣称触发制；禁止明示或暗示具体个股买卖时机/价格/走势预测；禁"领资料"式引流私域
- **小红书**（2026-06《金融类专业号专项治理公告》）：金融专业号认证仅对持牌机构；重点打击"港美股开通分享贴"；研报倒卖入刑风险
- **雪球**（2026-01专项治理）：定位"投资思考分享"非"投资建议"；估值分析转化为"估值讨论"不给目标价

## 三、雪球长文规范

### 3.1 定位
深度投研分享，引流到公众号/知识星球。雪球是"作品集+档案"，不承担涨粉KPI。

### 3.2 结构模板（金字塔）
```
标题：[标的] + [核心事件/矛盾] + [疑问/观点]

开头（悬念/故事型）：
  用一个数据或事件引入，制造阅读兴趣

核心观点（金字塔，先结论）：
  一句话亮明判断

分论点展开（2-4个）：
  ① 数据论据（标出处+可信度）
  ② 数据论据
  ③ 数据论据
  ④ 估值讨论（引用券商测算，注明"非本人目标价"）

风险提示（必须）：
  客观列出看空因素，不回避

结尾（呼应+引流+免责）：
  总结判断 + "更多深度分析见公众号同名" + "以上为个人研究分享，不构成投资建议"
```

### 3.3 合规要点
- 估值分析转化为"估值讨论"——呈现测算逻辑与假设，而非给出"目标价"
- "我分析/我判断"体，不用"建议买入""应该配置"
- 标注数据出处，规避"编造信息"嫌疑
- 不收费、不建群荐股、不导流违规

## 四、小红书信息差笔记规范

### 4.1 定位
基于自家调研的信息差/预期差笔记，搜索长尾承接。**非小白科普**。

### 4.2 结构模板（carousel 6-12页）
```
【标题】≤20字，带具体公司/药物名："关于X，市场搞错的3件事"

【封面】公司/药物名 + 反差数字（3:4竖版）

【Carousel】
  P1  封面
  P2  信息差结论先行：市场认知 ___ vs 公开数据 ___
  P3-10 每页一个数据论据（自制图表，标出处）
  P末  开放问题（拉评论）
  P末+1 风险提示："个人研究分享，不构成投资建议"

【正文】300-800字 + 结尾提问

【标签】#创新药 #医药 #具体药物名 #行业研究
```

### 4.3 合规要点
- 不晒实盘收益截图
- 不教开户（尤其港美股）
- 不搬研报原文（数据重新表述，自制图表）
- 标题带具体公司/药物名（吃搜索流量）
- 信息差有数据支撑，非空泛观点

## 五、抖音科普脚本规范

### 5.1 定位
算法公域流量，科普化降敏引流。抖音是"钩子化/科普化改编"，触达最大增量。

### 5.2 结构模板（小Lin说五段）
```
【选题】报告核心节  【时长】2-3min完整版（可拆条60-90s）

0-5s   钩子（数字冲击/反常识，逐字稿）
5-20s  为什么重要/背景（痛点提问）
20s-   论据一（数据+出处）［图表］
       论据二（数据+出处）［图表］
       论据三（数据+出处）［图表]
结尾   我的看法（开放讨论，不说满）
       字幕："个人研究分享，不构成投资建议"

【拆条点】标注3-4个可独立成条的切片
【自检】无身份宣称✓ 三不合规✓ 无买卖暗示✓ 风险提示✓ 科普化降敏✓
```

### 5.3 降敏要点
- 讲药物机制+临床数据+行业进展，**不讲投资价值/买入/估值**
- 视角=医药行业研究分享，非股票推荐
- 类比通俗化（如"松刹车 vs 松刹车+踩油门"）
- 数据标注出处（同行评审学术文献）
- 医疗提醒：不讲疗效/用药建议（避免被判入医疗类目）

## 六、引流路径设计

### 6.1 核心逻辑
三平台内容 = 报告的"结论+最强1-2个论据"（钩子）→ 公众号 = 报告的"完整论证"（中转）→ 知识星球 = 报告的"底稿+持续跟踪+互动问答"（核心产品）

### 6.2 合规引流路径
- **雪球**：长文末尾"更多深度分析见公众号同名"（雪球对导流相对宽松）
- **小红书**：主页简介"雪球/公众号同名"，内容不贴链
- **抖音**：主页简介"公众号同名"，内容不口播不贴链
- **知识星球**（12月起）：从公众号私域启动，不违反各平台导流规则

### 6.3 内容梯度
| 层级 | 平台 | 内容 | 目的 |
|------|------|------|------|
| 钩子 | 抖音/小红书/雪球 | 报告结论+1-2个最强论据 | 引流 |
| 中转 | 公众号 | 报告完整论证 | 沉淀私域 |
| 核心产品 | 知识星球 | 底稿+持续跟踪+互动问答 | 付费转化 |

## 七、一源四态

每篇投研底稿（一源）→ 四态输出：
1. 雪球长文（深度版，作品集）
2. 小红书信息差（简化版，搜索长尾）
3. 抖音科普脚本（降敏版，算法流量）
4. 公众号长文（完整版，私域沉淀）— 雪球长文直接转公众号

> 视频号不单独产出脚本（视频号=个股投研完整版，与抖音同源一次录制两版剪辑；剪辑点标注在抖音脚本末尾，不设独立视频号文件夹）

## 八、数据出处标注规范

遵循项目《信息来源可信度分级规范》：
- **[高]**：公司公告、监管文件、同行评审学术发表、ClinicalTrials.gov
- **[中]**：券商研报、咨询机构报告、行业数据库
- **[低]**：平台自媒体、个人分析、非专业媒体转述

标注格式：`(来源:[来源名称],[日期] | 可信度:[高/中/低]·[补充说明])`
