# BioTom 投研内容三平台引流管线

## Overview

将一份投研底稿转化为三平台引流内容（雪球长文 + 小红书信息差 + 抖音科普脚本），**按平台分文件输出**到 `输出/` 对应子文件夹（2026-08-19 结构）。

核心定位：**三平台都是知识星球引流手段**，内容是投研报告的简化/结论版；知识星球才是核心产品（付费完整报告）。

## 触发条件

用户说以下任一时触发：
- "把[标的]的投研输出到雪球/小红书/抖音"
- "生成BioTom三平台内容"
- "把这个报告分发到三平台"
- "投研内容多平台分发"

## 输入与输出

| 项目 | 说明 |
|------|------|
| **输入** | 投研底稿路径（通常在 `医药/[公司]_跟踪调研/` 下）+ 标的名 |
| **输出** | 三个 md 文件，按平台分存：`输出/雪球/YYYY-MM-DD_[标的].md`（长文照发）· `输出/小红书/YYYY-MM-DD_[标的]_信息差.md` · `输出/抖音/YYYY-MM-DD_[标的]_科普脚本.md`（抖音拆条脚本，末尾标注视频号完整版的同源剪辑点） |
| **格式** | 每个文件自带"引流主线 + 平台正文 + 合规自检"结构；三文件共用同一引流主线 |

## 工作流程

### Step 1: 读投研底稿

读取用户指定的投研底稿（或 `医药/[公司]_跟踪调研/` 下的主报告 + 学术验证文档）。提取：
- 核心投资逻辑链
- 关键临床数据（标注可信度等级）
- 催化剂时间线
- 风险全貌
- **最强的1-2个信息差/预期差**（引流钩子的核心）

### Step 2: 提炼引流主线

从底稿中提炼出**最有传播力的1条主线**——通常是：
- 一个反差数字（"35年无药上市的靶点被突破"）
- 一个预期差（"市场以为是X，公开数据其实是Y"）
- 一个悬念（"9月数据是试金石"）

这条主线贯穿三平台，但**呈现深度递减**：
- 雪球：完整论证（深度版）
- 小红书：信息差点（简化版）
- 抖音：科普化叙事（降敏版）

### Step 3: 生成雪球长文

**定位**：深度投研分享，引流到公众号/知识星球。

| 要素 | 要求 |
|------|------|
| 篇幅 | 2000-3000字 |
| 结构 | 金字塔（先结论后论据） |
| 开头 | 悬念/数据钩子引入 |
| 论据 | 3-5个分论点，每个配数据+出处 |
| 估值 | 估值讨论（引用券商测算，注明"非本人目标价"），不给目标价 |
| 语气 | "我分析/我判断"体 |
| 结尾 | 风险提示 + "个人研究分享，不构成投资建议" + 公众号引流（"更多深度分析见公众号同名"） |

### Step 4: 生成小红书信息差

**定位**：搜索长尾承接，引流到主页/公众号。

| 要素 | 要求 |
|------|------|
| 形态 | 信息差 carousel（6-12页，3:4竖版） |
| 标题 | ≤20字，带具体公司/药物名，"关于X，市场搞错的N件事"句式 |
| 封面 | 公司/药物名 + 反差数字 |
| 内容 | P2结论先行（市场认知 vs 公开数据）→ P3-N每页一个数据论据（自制图表）→ 末页开放问题+风险提示 |
| 正文 | 300-800字 + 结尾提问（拉评论） |
| 标签 | #创新药 #医药 #具体药物名 #行业研究（远离#股票 #A股 #荐股） |

### Step 5: 生成抖音科普脚本

**定位**：算法公域流量，科普化降敏引流。

| 要素 | 要求 |
|------|------|
| 时长 | 2-3min完整版（可拆条为60-90s切片） |
| 结构 | 小Lin说五段：痛点提问→故事引入→数据论证→类比拆解→开放讨论 |
| 降敏 | 讲药物机制+临床数据+行业进展，**不讲投资价值/买入/估值** |
| 类比 | 通俗化（如"松刹车 vs 松刹车+踩油门"） |
| 数据 | 标注出处（同行评审学术文献） |
| 结尾 | 开放提问 + 字幕"个人研究分享，不构成投资建议" |
| 拆条 | 标注3-4个拆条点（每个可独立成60-90s切片） |

### Step 6: 分平台输出三文件

按平台分别写入三个 md 文件（`输出/雪球/`、`输出/小红书/`、`输出/抖音/`），每个文件结构：

```markdown
# [标的]·[平台]内容

> 分析时间: YYYY-MM | 分析人: Tom Han（BioTom）
> 投研底稿来源: [底稿路径]
> 定位: 三平台=知识星球引流手段，核心产品是知识星球完整报告
> 引流主线: [1-2句话提炼本次最强引流钩子，三平台一致]

---

[平台正文内容]

---

## 合规自检

[该平台合规项，见下方六条纪律]
```

## 合规边界（六条纪律，三平台通用）

1. **身份**：统一"医药产业研究分享｜个人投资者视角"，不宣称任何金融专业身份
2. **内容三不**：不提买卖时机、不给目标价、不预测涨跌——结论停在"逻辑与看法"层
3. **小红书加码**：不晒实盘收益、不教开户、不搬研报原文（数据自制图表）
4. **抖音加码**：科普化降敏（讲行业事实+数字冲击，弱化投研结论）
5. **固定风险提示**：片尾+文末"个人研究分享，不构成投资建议"
6. **标签管理**：远离 #股票 #A股 #港股 #理财 #荐股

> 详细合规规范见 `references/合规与内容规范.md`

## 引流设计

**核心逻辑**：三平台内容是"钩子"（报告的简化/结论版），完整深度报告在知识星球。

**合规引流路径**（不在内容中直接说"加知识星球"）：
- 雪球：长文末尾"更多深度分析见公众号同名"
- 小红书：主页简介"雪球/公众号同名"，内容不贴链
- 抖音：主页简介"公众号同名"，内容不口播不贴链
- 知识星球（12月起）：从公众号私域启动，不违反各平台导流规则

**内容梯度**：
- 三平台 = 报告的"结论+最强1-2个论据"（钩子）
- 公众号 = 报告的"完整论证"（中转）
- 知识星球 = 报告的"底稿+持续跟踪+互动问答"（核心产品）

## 自检清单（输出前必跑）

- [ ] 三平台内容基于同一投研底稿，引流主线一致
- [ ] 雪球：估值讨论非目标价，"我分析/我判断"体，风险提示
- [ ] 小红书：信息差有数据支撑，自制图表，不搬研报，不晒实盘
- [ ] 抖音：科普化降敏，无身份宣称，三不合规，风险提示字幕；末尾标注视频号完整版剪辑点
- [ ] 三个文件分别写入 输出/雪球、输出/小红书、输出/抖音
- [ ] 数据出处标注（可信度分级）
- [ ] **变现对齐审查**（2026-08-19 起，项目 `方法论/变现总纲.md` §10.2）：每条内容的变现动作是什么（12月前=需求测试/信任积累；12月后=指向星球合规路径）？公开的是"方法"还是"判断"（判断只进星球）？流量反馈是中间变量，核心目的=变现，不可被模糊（dontbesilent 审查框架）
- [ ] **生成后 dbs 审查**（2026-08-19 用户确认）：三平台内容生成后，补一道 dbs-content 五维诊断（文字洁癖/封面标题/表达效率/认知落差/AI辅助），逐维给 ✅/⚠️/❌；❌ 不得定稿；小红书标题问题路由 dbs-xhs-title、AI 味路由 dbs-ai-check。本 skill 写，dbs 审
