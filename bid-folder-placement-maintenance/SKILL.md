# 招投标项目夹命名与归位维护

> 来源：2026-08-25 Tom 指令——「自动化项目和文件夹文档的命名一律按照项目本身的截止时间命名；台账维护之后要维护一遍项目文件夹所放的位置」。适用于 `~/Desktop/Tech/招投标简报/` 工作区。目录结构（08-25 扁平化后）：根目录 = 台账 + `01_可参与在途/` + `02_已截止归档/` + `公告存档/`（官方公告原文，每标必存）+ `竞争情报/`。

## 两条硬规则

### 规则一：命名 = 项目截止时间，不是发现日期

- 文件夹名：`YYMMDD短名`，其中 **YYMMDD = 该项目的递交截止或开标日期**（取台账「截止/开标时间」列的日期），短名为项目可识别简称。
  - 例：鲁山粮库开标 09-09 → 文件夹 `260909鲁山粮库`（哪怕评估报告是 08-24 写的）。
- 夹内文档同名前缀跟随文件夹：`YYMMDD短名+文档性质.md/.pdf`（如 `260909鲁山粮库项目评估报告.md`、`260909鲁山粮库采购清单评估.pdf`）。底稿/汇报版后缀规则不变。
- **例外**：台账标注「截止时间未核实」的暂存条目，保留原命名并在台账注明，核实截止时间后当日改名。
- 结果公告/合同公示类回溯补录条目：以结果公示日期为 YYMMDD（如乐山 260721、临沂 260806）。

### 规则二：归位 = 截止时间与今天比，不按相关度

每轮台账维护完成后，遍历 `招投标简报/01_可参与在途` 与 `02_已截止归档`（两组均与台账平级，08-25 17:40 起不再有 `项目/` 中间层）全部文件夹：

1. 从台账找到该项目的「截止/开标时间」；
2. **截止时间 > 今天 → 必须在 01_可参与在途；≤ 今天 → 移入 02_已截止归档**；
3. 低相关/赛道观察条目同样按此规则归位（08-25 起新口径：不再按「赛道观察放归档组」的旧惯例）；
4. 同一项目出现多个文件夹 → 合并为一个，保留最新版报告，旧版文件随迁；
5. 移动后检查台账正文中引用的旧路径并同步更新。

## 操作顺序（每轮）

1. 先完成台账条目本身的更新（新增/状态变更）；
2. 新建项目夹时直接按截止日期命名建入正确组；
3. 遍历核对两组文件夹归属，执行 mv；
4. `grep "26[0-9]\{6\}"` 检查台账及关联文档中的路径引用，修正失效路径（注意旧文档可能仍引用 `项目/` 前缀，一律改为平级路径）；
5. 在台账「最近更新」行追加本次归位动作记录。

## 判断捷径

- 台账在途表里的项目 = 应在 01 组；已截止表的 = 应在 02 组。**台账是唯一真源**，文件夹位置只是台账状态的物理映射。
- 拿不准某夹对应哪条台账 → 用文件夹短名 grep 台账。
